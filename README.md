# 智能五子棋

纯前端五子棋人机对弈游戏，无需后端、无需安装，打开即玩。

## 在线试玩

- GitHub Pages: https://zilanglian208-sudo.github.io/gomoku/
- ZCode Sites: https://gomoku-game-nj84.zai-ai.site

## 玩法与功能

- 黑白轮流落子，横、竖、斜任一方向连成五子获胜
- AI 三档难度：入门 / 进阶 / 高手（深度搜索）
- 悔棋、提示、先手方切换、战绩统计（本地保存）
- 胜利连线动画、悬停预览、最后一手标记、坐标显示

## AI 引擎

- 模式识别评估：四个方向识别连五 / 活四 / 冲四 / 活三 / 眠三 / 活二 / 眠二（含跳子形态）
- 战术优先级硬保证：我方成五 > 挡对方成五 > 我方活四 > 挡对方活四，任何难度下「能赢必赢、该挡必挡」
- 困难模式使用 α-β 剪枝的极大极小搜索（深度 4），中盘思考约 100ms
- AI 计算全部在玩家浏览器本地进行，服务器只分发静态文件，天然支持千人同时在线

## 本地运行

直接双击 `index.html` 即可；或起一个静态服务器：

```
npx serve .
```

## 运行测试

需要 Node.js：

```
node test.js
```

覆盖胜负判定、AI 能赢必赢 / 该挡必挡（冲四、跳四、贴边四、活三）、对弈完整性与性能共 19 项断言。
